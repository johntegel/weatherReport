We are here to present our mini project, “Weatherwise – Weather Forecasting Application.”

Weatherwise is a web-based weather application developed to provide users with real-time weather information and weather forecasts in a simple and user-friendly interface.

Our application allows users to search for a location and view important weather information such as temperature, humidity, wind speed, pressure, and forecast details.

The main objective of this project is to provide weather information quickly and conveniently through a web application.

We developed the project using web technologies and integrated a weather API to obtain weather information.

We will now explain the existing system, proposed system, advantages, modules, technologies used, and the working output of our application.
